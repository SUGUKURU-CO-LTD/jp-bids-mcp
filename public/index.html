# MCP対応クライアントにこのURLを登録
https://mcp.bid-jp.com/mcp

# トランスポート: Streamable HTTP
# 認証: OAuth 2.0（自動）

claude_desktop_config.json に追加：

{
  "mcpServers": {
    "jp-bids": {
      "command": "npx",
      "args": ["--yes", "mcp-remote",
              "https://mcp.bid-jp.com/mcp"]
    }
  }
}

.cursor/mcp.json に追加：

{
  "mcpServers": {
    "jp-bids": {
      "url": "https://mcp.bid-jp.com/mcp"
    }
  }
}

顧客が実際にやること

AIに話しかけるだけで、入札業務が変わる

会話例 1

「IT系の入札を探して」

全国の入札情報から条件に合う案件を検索 (`search_bids`)。自社条件に合う順にランク付け (`rank_bids`)。

会話例 2

「この仕様書の要件を整理して」

案件メタデータから必須要件・評価項目・提出書類を構造化して整理 (`extract_bid_requirements`)。※外部資料抽出は既定OFF。最終判断は必ず公式書類で確認。

会話例 3

「上位5件をCSVで出力して」

選択した案件の順序を保ったままCSVまたはJSON形式でエクスポート (`export_bid_shortlist`)。

会話例 4

「直近の新着案件を確認して」

直近1〜30日間に公告された新着入札案件を一覧取得 (`list_recent_bids`)。毎朝の営業チェックに活用。

会話例 5

「うちの条件に合うか確認したい」

自社プロファイルと案件を比較採点 (`rank_bids`)。※参考情報としての適合度整理であり、参加資格の確定判定ではありません。

会話例 6

「対話画面で絞り込みたい」

対話型検索アプリ (`search_bids_app`) を開き、MCP Apps 互換クライアントで表形式のワークスペースを直接操作。

7つのAIツール

🔍

search_bids

官公需入札検索。キーワード・機関名・地域・カテゴリ・期間で柔軟に絞り込み。

📊

rank_bids

自社プロファイル・優先語句に基づき、候補案件の適合度と緊急度を0〜100で採点。

📅

list_recent_bids

直近1〜30日間に公告された新着案件を一覧取得。毎朝の新着チェックに対応。

📑

get_bid_detail

指定した案件の詳細情報・公告内容・添付ファイル一覧を取得。

📄

extract_bid_requirements

案件メタデータから必須要件・評価項目・提出書類を構造化抽出（※外部資料抽出は既定OFF）。

📤

export_bid_shortlist

選択した案件リストを指定順序のままCSVまたはJSON形式でエクスポート。

🖥

search_bids_app

MCP Apps UI対応クライアントで、表形式の対話型入札検索ワークスペースを表示・操作。
