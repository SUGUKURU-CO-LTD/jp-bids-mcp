## JP Bids MCPでできること

官公需公告を検索し、検討したい案件を画面で選び、CSVの候補リストとして受け取れます。データ出典は中小企業庁の官公需情報ポータルサイトです。サービス提供者はスグクル株式会社です。

JP Bids MCP自体の利用料は無料です。Claude等のAIクライアントの利用料は別途発生する場合があります。利用できるコネクタ機能や組織権限はクライアント側の条件によります。

案件探しと社内検討を支援します。入札への申込み、資格登録、提出手続きは、この検索・CSV操作では実行されません。

## Claudeに接続する

1. Claudeの「カスタマイズ → コネクタ」を開きます。
2. カスタムコネクタの追加画面で、名前にJP Bids MCP、URLに https://mcp.bid-jp.com/mcp を入力します。
3. 表示されたOAuth認可を完了します。
4. 会話のコネクタ設定でJP Bidsが有効になっていることを確認します。

Team・Enterpriseでは組織の管理者による事前追加が必要な場合があります。画面名や選択肢が異なる場合は[Claude公式ヘルプ](https://support.claude.com/ja/articles/11175166)を確認してください。リモート接続を使う場合、ローカル開発用の設定ファイル編集はこの手順に含まれません。

## 最初の検索

次の依頼例をClaudeへ入力します。

> JP Bidsのsearch_bids_appで、東京都・役務、件名に「システム」を含む公告を最大3件検索し、AI Bid Workspaceを表示してください。

検索結果は時期や条件で変わります。検索ヒット総数と、今回取得して画面に表示する件数は別です。3件表示されても、ヒットした全案件を取得したという意味ではありません。

「システム」は操作例です。利用時には地域、業務分野、件名の語句を自社に合う条件へ変更してください。短時間に条件を変えて繰り返し実行することは避けます。

## 案件を選んでCSVを取得する

1. 一覧で必要な案件のチェックボックスを選びます。右側に表示している詳細案件と、CSV対象としてチェックした案件は別です。
2. 選択件数を確認し、「選択CSV」を1回押します。
3. 画面の通知を確認します。通知の意味は次の表のとおりです。
4. CSVを取得できたら、選択した件数・案件名・発注機関・理由の対応を確認して保存します。

| 表示・結果 | 意味 | 次の操作 |
| --- | --- | --- |
| CSV出力をHostへリクエストしました | ホストへ保存を依頼した | 実際にファイルを受け取れたか確認。通知だけで保存完了と判断しない |
| CSVをクリップボードにコピーしました | CSV本文をコピーした | テキストエディタ等へ貼り付けて内容を確認。CSVとして保存し、UTF-8・カンマ区切りで読み込む |
| 選択CSVリクエストをchatへ送信しました | チャットへツール実行の依頼を送った | まだCSV取得完了ではない。チャット側の応答を確認する |
| 操作文をコピーした旨の通知 | CSVではなく依頼文をコピーした可能性がある | 貼り付け内容を確認。操作文をCSVファイルとして扱わない |
| Hostにブロックされた／エラー | 保存・コピーまたはツール実行に失敗 | 連打せず、通知とクライアント情報を確認して問い合わせる |

今回の本番検証では、異なる発注機関の2案件を選択したCSVファイルを取得し、案件・発注機関・理由が対応していることを確認しています。すべてのホストで同じ保存・コピー動作になるとは限りません。

「全件CSV」は、現在の検索応答に含まれる取得済み案件が対象です。ポータルの検索ヒット総数すべてを自動取得する操作ではありません。一度の出力は最大50件です。この対象範囲は公開コードで確認した仕様であり、全件CSVの新たな実機試験を実施したという意味ではありません。

## 結果の読み方

- 件名・発注機関・公式URLを、検討対象を特定する情報として使います。
- 提出期限や開札日が空欄・不明の場合、期限がないという意味ではありません。公式公告で確認します。
- スコアは検討優先度の参考です。落札確率や参加資格の合否ではありません。
- 詳細スナップショットは検索時点の情報です。公式公告の更新を自動保証しません。
- 公式URLが共通ポータルの入口や添付資料に直接つながる場合があります。対象案件の件名・機関が合っていることを確認します。
- CSVでは案件Key・機関名・理由の対応を保ちます。表計算ソフトがIDや日付を自動変換する場合は、取り込み時の列の型を確認します。

## 困ったとき

| 症状 | 確認・対処 |
| --- | --- |
| コネクタを追加できない | Claude側の契約・組織権限、公式ヘルプ、入力URLを確認 |
| 7ツールが見えない | 接続先と会話内の有効化状態を確認。古い接続との混同を調べる。認証情報を手作業で共有しない |
| 画面が出ずテキストのみ | MCP Appsの表示対応・管理者設定を確認。テキスト応答成功とUI描画成功を分けて扱う |
| 0件だった | 検索条件と対象地域を見直す。案件の存在を保証する例ではない |
| 案件参照が無効・期限切れ | 古い参照を推測・書き換えない。通常利用では利用者が再検索を選び、最新結果から選び直す。回数制限付きの検証中は指定された停止条件を優先 |
| CSV件数や機関名・理由が合わない | そのCSVを業務判断に使わず、選択状態・ファイル・エラー通知を保全して報告 |
| 文字化け・1列にまとまる | CSVファイルをUTF-8・カンマ区切りとしてインポート。直接貼り付けだけで正しい列に分かれるとは限らない |
| 公式URLで目的の案件が出ない | 入口ページかどうか確認し、件名・発注機関から公式サイト内で探す。URL到達だけで原本照合済みとはしない |

問い合わせには、日時、クライアント名、操作、表示されたエラー、対象の公開案件名を添えます。通常の技術的な不具合は[GitHub Issues](https://github.com/SUGUKURU-CO-LTD/jp-bids-mcp/issues)へ。アクセストークン、認可コード、署名付きbid_ref、個人情報は公開投稿しません。秘密情報を含む相談は[会社の問い合わせ窓口](https://sugu-kuru.co.jp/contact)の受付方法を確認して連絡します。
