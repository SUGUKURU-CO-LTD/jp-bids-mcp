# 日本官公需入札検索スキル (JP Bids Procurement Skill)

ユーザーが日本国内の官公需入札案件、調達公告、仕様書要件、入札参加資格について質問・探索する際に本スキルを活用してください。

## 提供ツール一覧と使い分け

1. **`search_bids_app` (推奨 / MCP Apps 対応環境)**:
   - 日本全国の官公需入札情報を検索し、ChatGPTのチャットキャンバス内に対話型ワークスペース（AI Bid Workspace）をインライン描画します。
   - ユーザーが入札結果をカード一覧で閲覧・選択・比較したい場合に最優先で使用します。
2. **`search_bids` (テキスト・データ検索)**:
   - キーワード、都道府県、発注機関、業務区分、公告日・締切日などの条件で入札情報を検索し、要約テキストと構造化データを取得します。
   - テキストやデータ出力だけで十分な場合に使用します。
3. **`get_bid_detail`**:
   - 特定の案件番号（`key` または `bid_ref`）に基づき、詳細情報（品名、納期、資格等級、公告URL等）を取得します。
4. **`rank_bids`**:
   - 検索結果または指定案件に対して、企業の強みや希望キーワード（IT、保守、クラウド等）に基づく適合度スコアリングと優先度（pursue / review / skip）の判定を行います。
5. **`extract_bid_requirements`**:
   - 案件の概要・公告文から、参加資格（等級区分、地域制限等）、提出書類、技術要件を抽出・整理します。
6. **`export_bid_shortlist`**:
   - 追跡・検討対象として選定された案件を CSV または JSON 形式でエクスポートします。
7. **`list_recent_bids`**:
   - 直近の新着案件や締切間近の案件を迅速に一覧取得します。

## 安全性およびデータに関する注記

- 本モック環境で提供されるデータは、オフライン検証用のフィクスチャ（`KKJ-TEST-001` 等）です。実際の入札判断を行う際は、必ず公式調達書類（KKJポータルサイトまたは発注機関の公告）をご確認ください。
