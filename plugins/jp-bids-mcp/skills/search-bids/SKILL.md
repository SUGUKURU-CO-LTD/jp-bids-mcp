# 日本官公需入札探索スキル (JP Bids Procurement Skill)

ユーザーが日本国内の官公需入札案件、調達公告、仕様書要件、入札参加資格について質問・探索する際に本スキルを活用してください。

## ⚠️ 重要：MCP 接続状態に応じた動作モードの区別

本プラグインを GitHub Marketplace からインポートした単体環境（クラウド版 ChatGPT 等）では、**ナレッジ支援・プロンプトガイド（モード A）** として動作します。  
Claude Desktop やローカル/リモート MCP サーバーがクライアントに直接接続されている場合のみ、**MCP ツール連携（モード B）** を利用できます。

実 MCP ツールが接続されていない環境で、ツールが利用可能であるかのように誤認させたり、存在しないツール呼び出しを行わないよう注意してください。

---

### モード A：実 MCP ツールが未接続の環境（ナレッジ・探索支援）
クライアントに `search_bids` や `search_bids_app` ツールが提供されていない場合、以下の支援を行ってください：

1. **中小企業庁 官公需情報ポータルサイト (KKJ) の活用案内**:
   - 公式ポータルサイト（`http://www.kkj.go.jp/`）の検索画面における最適な検索キーワード、業種分類（物品・役務・工事）、発注地域（都道府県・省庁）の絞り込み条件の設計を支援する。
2. **入札要件・公告資料の読解・整理支援**:
   - ユーザーから提供された公告文や仕様書のテキストから、入札参加資格（全省庁統一資格の等級・地域）、提出期限、開札日、技術要件、必要書類チェックリストを整理・抽出する。
3. **案件適合度・優先度の評価フレームワーク提供**:
   - 企業の強みや得意分野に応じた評価軸（業務適合度・リソース余裕度・納期妥当性）を提示し、追跡すべき案件の優先順位付け（pursue / review / skip）を支援する。

---

### モード B：JP Bids MCP サーバー接続環境（ツール自動実行）
クライアントに JP Bids MCP サーバー（7ツール）が接続されていることが確認できる場合、以下のツールを状況に応じて適切に呼び出します：

1. **`search_bids_app` (推奨 / MCP Apps 対応環境)**:
   - 入札結果をカード一覧で確認し、インタラクティブに操作したい場合に最優先で使用。チャットキャンバス内に対話型ワークスペース（AI Bid Workspace）を描画。
2. **`search_bids` (テキスト・データ検索)**:
   - キーワード、都道府県、発注機関、業務区分、日付範囲での入札公告検索。
3. **`get_bid_detail`**:
   - 特定の案件番号（`key` または `bid_ref`）に基づく詳細情報の取得。
4. **`rank_bids`**:
   - 案件群に対する適合度スコアリングと優先度判定。
5. **`extract_bid_requirements`**:
   - 公告情報からの参加資格・提出要件・技術仕様の自動抽出。
6. **`export_bid_shortlist`**:
   - 追跡案件の CSV または JSON 形式でのエクスポート。
7. **`list_recent_bids`**:
   - 新着・締切間近案件のクイック一覧。
